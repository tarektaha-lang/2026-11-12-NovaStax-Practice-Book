Compile repairs before papers.py

Automatic fixes in latex.py and arabic_math.py so a single bad table, figure label, or maths fragment does not drop a section from the bound book.

compile_pdf() Missing character Extra alignment tab

Why exit code 1

papers.py may print “OK: … bound as …pdf” and still exit 1 when any section failed. After each compile, compile_pdf() in latex.py either raises on ! errors or on any Missing character line in the log (then deletes the PDF). Failed sections are omitted from numbering and binding.

Array column alignment

Seen on: mathematics_ar_iq08 §2.5 — ! Extra alignment tab has been changed to \cr.

Cause: Model wrote four cells per row (4 & -3 & 2 &X) but declared {c|c|c} (three columns).

Fix: align_array_columns() in unframed() appends |c until the preamble matches the widest row. Skips \multicolumn and nested tables.

TikZ range labels (ASCII hyphen)

Seen on: mathematics_ar_dz07 §2.2 — four Missing character: There is no - (U+002D) in Noto Naskh inside histogram axis labels {0-5}, {6-10}, …

Cause: Figure TikZ uses plain text node labels with ASCII hyphen-minus. Prose already maps - to U+2010 (HYPHEN); labels in drawings never went through that path.

Fix: tikz_range_label_hyphens() in standard_lines() rewrites {digits-digits} labels only (does not touch -{Stealth[…]} or coordinates).

Arabic verse in \mathit

Seen on: arabic_ar_iq08_t1 §7.1 — hundreds of missing glyphs at U+1EE00 (AMS Arabic math letters) in Noto Naskh family=rm.

Cause: Qur’an snippets like $\mathit{«\waw …»}$ route CLS macros through the text italic font instead of NagwaArabicMath.

Fix: strip_text_math_fonts() at the start of arabic_maths() / arabic_maths_letters() removes \mathit, \mathrm, etc. wrappers so \waw, \alef, … stay in the maths face.

Sarf patterns in maths

Seen on: arabic_ar_iq08_t1 §3.2 — tashkeel and letters ئ, ى in cmmi12.

Cause: MCQ options mix \kaf-style macros with vocalisation marks and hamza/alef-maksura letters left as Unicode inside $…$.

Fix: In arabic_math.letters_for_tex(): drop tashkeel; map ى, ئ, ء, ؤ to CLS macros (and MATH_LETTER_MAP for Lua mathcodes).

How to verify

python scripts/papers.py mathematics_ar_iq08 -s 2.5
python scripts/papers.py mathematics_ar_dz07 -s 2.2
python scripts/papers.py arabic_ar_iq08_t1 -s 3.2
python scripts/papers.py arabic_ar_iq08_t1 -s 7.1

Each command should report the section as a multi-page paper with no “would not compile” line, and exit 0 when every section in scope succeeds.
