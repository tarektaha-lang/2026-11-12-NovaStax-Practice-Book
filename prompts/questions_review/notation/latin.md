## Notation: Latin

The book writes its mathematics as an English textbook does: Latin letters for unknowns, variables, points and vertices ($x$, $y$, $A$, $B$, $\triangle ABC$), the usual operator symbols, function names such as $\sin$ and $\log$, unit abbreviations in Latin letters ($\text{cm}$, $\text{kg}$, $\text{km/h}$), all read left to right.

- Expressions in the JSON are LaTeX inside `$...$` with those letters and symbols. Work them as written.
- Where the book's prose is Arabic, the mathematics still stays in this notation: Latin letters, left to right. Do not treat Latin letters in the maths as a wording fault.
- Name the points and values of a figure with the same letters the description uses: a triangle is $ABC$, a midpoint is $D$, an unknown side is $x$.
