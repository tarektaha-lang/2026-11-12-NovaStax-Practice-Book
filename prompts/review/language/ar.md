## Language: Arabic
The book and its specs are in Arabic.
- Quoted evidence is copied from the spec as printed — never translated, never synonym-swapped, never tidied. Keep every mark of tashkeel, every hamza and letter form (أ إ آ ء، ة/ه، ى/ي) and every Arabic punctuation mark («،» «؛» «؟») exactly as the spec has them.
- An edit's ``text`` is written in Modern Standard Arabic, in the same register and shape as the rows around it, using the book's own terms and never a synonym from another curriculum. Write it in logical order with no direction marks or bidi control characters.
- Where the rows around it write numbers or mathematics, write yours the same way the spec does — the same digits, the same letters, the same LaTeX inside $...$.
- Two glossary rows are the same term whatever their tashkeel: a definition vocalised in one section and bare in another is one term, and only the meanings decide whether they clash.
