## Notation: Latin

The paper writes its mathematics as an English textbook does: Latin letters for
points, vertices and unknowns ($A$, $B$, $x$), read left to right, with Latin unit
abbreviations ($\text{cm}$, $\text{kg}$).

- Label a point with the letter the description gives it, in maths: `{$A$}`. Name
  the coordinate the same way, `\coordinate (A)`, so the picture reads as the
  description does.
- A value or an unknown on a segment or an angle is set as the description writes
  it: `{$6\text{ cm}$}`, `{$2x + 1$}`, `{$105^\circ$}`.
